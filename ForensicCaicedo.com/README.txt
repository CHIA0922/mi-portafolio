# ForensicCaicedo.com

Portafolio web académico/proyectado de Chiara Nicole Caicedo Jama.

## Archivos
- `index.html` — estructura de la página.
- `style.css` — diseño, responsive, modo claro/oscuro y efectos de brillo.
- `script.js` — cambio español/inglés, tema, menú móvil, casos interactivos, visor de evidencia y formulario.

## Cómo abrirlo en VS Code
1. Descomprime la carpeta.
2. Abre la carpeta `ForensicCaicedo` en Visual Studio Code.
3. Abre `index.html` en el navegador, o usa la extensión Live Server.
4. No necesita servidor ni base de datos para la demostración.

## Nota académica
La identidad profesional está planteada como una proyección a 10 años (2036). Los casos, credenciales, acreditaciones, publicaciones y formulario son simulados para fines académicos y no representan investigaciones, clientes o acreditaciones reales.
